Video API Documentation

API v1 cho catalog video ClipViet.live. Backend Cloudflare Worker, lưu catalog trong KV riêng, phiên quản trị dùng Telegram Authentication.

Trạng thái tích hợp: Mã API đã được bổ sung vào branch phát triển. Cần tạo binding VIDEO_CATALOG, cấu hình hostname media, xác thực Telegram và kiểm thử trước khi bật. Không có stream hoặc nguồn bên thứ ba nào được tự động cấp quyền.

AppleCMS provider API

Adapter tương thích AppleCMS V10 theo đặc tả tích hợp đã kiểm tra. JSON API được Worker gọi server-side để tránh lỗi CORS; media HLS/MP4 vẫn được browser tải trực tiếp từ CDN nguồn.

Provider IDs: souavzy (main), apiyutu, lbapi9, slapibf, jipinvip1 (backups). The supplied 2026-11-25 probe report measured historical catalog sizes of 130,740 / 228,064 / 340,304 / 265,410 / 74,701 respectively; live totals can change. douapi.cc, ddapi.cc, and zy.xiaomaomi.cc were reported offline and are excluded. hsex.men had no public API/OpenAPI/Swagger endpoint in that report and is not configured as a provider. Pagination luôn dùng page, pageCount, limit, total trong response; không giả định mọi nguồn trả 20 mục/trang.

GET/api/catalog/videos

Danh sách video. Nếu không truyền sourceId, Worker thử nguồn chính rồi lần lượt nguồn dự phòng khi upstream lỗi. Không failover khi có categoryId vì category IDs không tương thích giữa các nguồn. Kết quả rỗng hợp lệ và không kích hoạt failover.

{ "provider": { "id": "souavzy", "name": "Souavzy · Main" }, "items": [{ "uid": "souavzy:62843", "id": "62843", "sourceId": "souavzy", "title": "..." }], "page": 1, "pageCount": 6537, "total": 130740, "limit": 20 }
GET/api/providers/{sourceId}/videos/{vodId}

Chi tiết video gồm field mapping và lines[].episodes[].url. Chỉ HTTPS playback URL được trả về. ID nội bộ luôn ghép source ID để tránh trùng giữa các nguồn.

GET/api/providers/health

Yêu cầu Telegram admin session. Kiểm tra API list/categories, metadata sample, pagination và có playback URL hay không. Đây là API health check, không thay thế kiểm thử phát thực tế trên trình duyệt.

AppleCMS mapping & playback parser

  • ac=list chỉ dùng lấy class[]; lọc leaf category theo type_pid. ac=detail dùng cho list/detail.
  • Tham số: pg, t, wd, ids. Tìm kiếm được URL-encode UTF-8.
  • Mapping: vod_id → id, vod_name → title, vod_pic → poster, vod_content → description với fallback vod_blurb, vod_time → updatedAt, vod_play_url → lines.
  • Play URL parsing bắt buộc theo $$ (line) → # (episode) → lastIndexOf('

    Origin dự kiến; DNS/custom domain chưa được tạo. Không gọi URL này cho đến khi Worker được triển khai và health check thành công. Provider API routes use the same Worker origin at /api/providers and /api/catalog.

    Endpoints

    GET/health

    Trạng thái dịch vụ và cấu hình. Không trả về secret.

    POST/auth/telegram

    Nhận payload Telegram Login Widget, xác minh chữ ký và auth_date, chống replay, cấp session cookie.

    GET/auth/me

    Kiểm tra session hiện tại.

    POST/auth/logout

    Hủy session cookie.

    GET/channel/verify

    Kiểm tra bot có quyền đăng và tài khoản hiện tại có quyền quản trị channel.

    POST/channel/publish

    Gửi video tới channel đã cấu hình phía máy chủ; cần session, quyền channel, allowlist media host và rights attestation.

    GET/videos

    Danh sách metadata video đã xuất bản. Không trả media URL trong danh sách.

    200 OK
{ "data": [{ "id":"uuid", "title":"Video title", "poster_url":"https://cdn.example/video.jpg", "genre":"Documentary", "country":"Vietnam", "duration":"12:30", "created_at":"ISO-8601" }], "count": 1 }
    GET/videos/{id}

    Chi tiết video đã xuất bản, bao gồm media URL đã allowlist.

    200 OK
{ "data": { "id":"uuid", "title":"Video title", "media_url":"https://media.example/video.mp4" } }
    GET/admin/videos

    Liệt kê catalog quản trị. Yêu cầu session Telegram hợp lệ và user ID nằm trong allowlist.

    POST/admin/videos

    Tạo video. Yêu cầu session quản trị, rights_confirmed=true, HTTPS media URL nằm trong VIDEO_MEDIA_HOSTS.

    {
  "title":"Video title",
  "description":"Description",
  "media_url":"https://media.example/video.mp4",
  "poster_url":"https://media.example/poster.jpg",
  "genre":"Documentary",
  "country":"Vietnam",
  "duration":"12:30",
  "status":"published",
  "rights_confirmed":true
}

    Trả về 201 Created. Có thể đặt status:"draft" để lưu nháp.

    DELETE/admin/videos/{id}

    Xóa một video khỏi catalog. Yêu cầu session quản trị.

    Authentication & authorization

    • Đăng nhập qua Telegram Login Widget, xác minh HMAC ở Worker.
    • Session cookie HttpOnly, Secure, SameSite=Strict.
    • Chỉ Telegram User ID nằm trong TELEGRAM_ALLOWED_USER_IDS được truy cập quản trị.
    • Không gửi Bot Token hoặc Session Secret từ trình duyệt.

    Rate limits & payload constraints

    • JSON request body tối đa 16 KiB theo parser hiện tại.
    • Catalog tối đa 1.000 video trong KV key đơn.
    • Metadata: title 160 ký tự, description 2.000, genre/country 80.
    • Rate limiting ở Cloudflare edge chưa được cấu hình; không mở API công khai cho đến khi có rule phù hợp.
    • KV là eventual-consistency storage; catalog đơn-key phù hợp giai đoạn thử nghiệm, chưa phải CMS quy mô lớn.

    Proxy & delivery

    JSON API được Worker gọi server-side để xử lý CORS. Playlist HLS và segment TS được phát trực tiếp từ CDN nguồn trong trình duyệt; Worker không proxy video, không relay segment và không tạo endpoint tải xuống. Player dùng native HLS trên iOS và HLS.js trên trình duyệt desktop hỗ trợ MSE. Thực tế phát vẫn cần nghiệm thu trên thiết bị thật.

    Player support

    • MP4/WebM: dùng HTML5 video khi máy chủ trả MIME type đúng và hỗ trợ byte-range.
    • HLS: Safari/iPhone dùng native HLS; desktop dùng HLS.js 1.5.18 khi Hls.isSupported().
    • Không proxy, tải xuống, scrape hoặc relay stream không có quyền.

    Error format

    { "error": "Human-readable error" }

    HTTP 400 dữ liệu sai; 401 thiếu session; 403 không đủ quyền; 404 không tìm thấy; 503 binding/catalog chưa sẵn sàng.

    Example request

    curl -H "Accept: application/json" \
