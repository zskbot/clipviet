Static Video Catalog

Kiến trúc đang sử dụng: GitHub Pages chỉ phục vụ static HTML/CSS/JS/JSON. GitHub Actions lấy dữ liệu AppleCMS theo lịch và tạo data/catalog.json trong artifact Pages. Không có API server, Cloudflare Worker, Netlify hoặc Vercel trong luồng triển khai này.

Catalog endpoints

GET../data/catalog.json

File JSON công khai chứa metadata, provider health, danh mục lá và các đường phát HTTPS. Catalog được tạo trong mỗi lần deploy; lịch đồng bộ mặc định 6 giờ.

AppleCMS V10 source APIs

  • GET {BASE}?ac=list: chỉ lấy class[]; chỉ hiển thị danh mục lá có type_pid != 0.
  • GET {BASE}?ac=detail&pg=1: lấy danh sách phim đầy đủ metadata và poster.
  • GET {BASE}?ac=detail&t={type_id}&pg=1: lọc theo danh mục.
  • GET {BASE}?ac=detail&wd={keyword}&pg=1: tìm kiếm.
  • GET {BASE}?ac=detail&ids={vod_id}: chi tiết video.

Năm provider được khai báo trong scripts/sync-pages-catalog.mjs: Souavzy (main), ApiYutu, LBApi9, Slapibf và JipinVIP1. Domain/API availability và số lượng catalog có thể thay đổi; trạng thái hiển thị lấy từ lần đồng bộ gần nhất, không phải bảo đảm SLA.

Refresh and pagination

Workflow lấy tối đa 3 trang mỗi provider mỗi lần chạy (có thể điều chỉnh 1–5 bằng workflow_dispatch). Tôn trọng pagecount và limit trả về; không giả định mọi nguồn đều có 20 video/trang. Các request được thực hiện tuần tự với khoảng nghỉ và một lần retry.

Playback delivery

Video HLS/MP4 được phát trực tiếp từ CDN nguồn trong trình duyệt. iPhone/Safari dùng native HLS; desktop dùng HLS.js khi cần. GitHub Pages không proxy manifest hoặc segment, tránh biến Pages thành relay video. Playback thực tế phụ thuộc CORS, hotlink policy, TLS và tình trạng CDN của từng nguồn.

Source monitor

Mở trang trạng thái provider. Trang monitor chỉ đọc catalog đã xuất bản. Không có API key hoặc token được nhúng trong frontend.

Rights and age safeguards

Chỉ đưa vào catalog nội dung mà bên vận hành có quyền phân phối, cùng metadata và poster tương ứng. Cần cơ chế tiếp nhận yêu cầu gỡ nội dung và xử lý khiếu nại. Cổng 18+ là tự khai, không phải xác minh danh tính hoặc độ tuổi.
